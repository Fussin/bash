# Web Dashboard

This is a SvelteKit application that serves as the primary user interface for Project Chimera.

## Development

1. Navigate to this directory: `cd apps/web-dashboard`
2. Install dependencies: `pnpm install`
3. Start the development server: `pnpm dev`

The application will be available at `http://localhost:5173`. API requests to `/api` will be proxied to the API Gateway running on `http://localhost:8080`.
