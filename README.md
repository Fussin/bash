# Project Chimera

This is the monorepo for Project Chimera.

## Getting Started

1.  Ensure you have `poetry`, `pnpm`, and `task` installed.
2.  Run `task bootstrap` to install all dependencies and set up hooks.
3.  Copy `.env.example` to `.env` and configure as needed.
4.  Run `task up` to start the local development environment via Docker Compose.
5.  Run `task down` to stop the environment.

See `Taskfile.yml` for other common commands.
